## 05:45-05:54 UTC - Benchmark Selection Research

### Question from Myco: "What do you know about benchmark options"

Researched three candidate benchmarks recommended by ChatGPT 5.2 and hackathon mentor:

### 1. MMLU-Pro (Ollama-MMLU-Pro)
- **Link:** https://github.com/chigkim/Ollama-MMLU-Pro
- **Type:** Multiple choice (10 options, harder than MMLU)
- **Categories:** Math, physics, chemistry, law, engineering, etc.
- **Pros:** Easy to run via OpenAI API, fast, clear scoring, subset selection
- **Cons:** Tests LLM knowledge > agent capabilities, doesn't exercise OpenClaw features

### 2. GAIA ⭐ **RECOMMENDED**
- **Link:** https://huggingface.co/datasets/gaia-benchmark/GAIA
- **Type:** Real-world Q&A requiring tool use, multi-step reasoning, file handling
- **Size:** ~450-466 questions with unambiguous answers
- **Structure:** 3 difficulty levels
  - **Level 1:** ≤5 steps, 0-1 tool, designed for strong LLMs
  - **Level 2:** 5-10 steps, multiple tools
  - **Level 3:** Up to 50 steps, any tools, long-horizon planning
- **Pros:**
  - ✅ Designed for agents with tools (perfect for OpenClaw)
  - ✅ Tests what makes OpenClaw different (web search, file handling, multi-step)
  - ✅ Unambiguous grading (single factoid answers)
  - ✅ Multiple difficulty levels (MVP = Level 1)
  - ✅ Well-established leaderboard
- **Cons:** Some questions need file attachments, slower than multiple choice

### 3. AgentBench
- **Link:** https://github.com/THUDM/AgentBench
- **Type:** 8 interactive environments (OS, DB, KG, WebShop, AlfWorld, etc.)
- **Pros:** Most comprehensive agent evaluation, multi-turn, diverse capabilities, academic credibility (ICLR'24)
- **Cons:** 
  - ❌ Complex Docker setup
  - ❌ High resources (WebShop needs 16GB RAM)
  - ❌ Time-intensive (1-5min setup per env)
  - ❌ Too ambitious for hackathon deadline

### Decision Context from Myco (05:54 UTC)

Myco provided detailed GAIA breakdown:
- **GAIA = "General AI Assistants"** benchmark
- Tests real-world, tool-using agents on multi-step, web, multimodal reasoning
- Tasks conceptually easy for humans but tedious (requires planning, browsing, files, code)
- Evaluated on factual correctness
- Level 1 perfect for MVP (breakable by strong LLMs, single file/web lookup + inference)

2. Track: accuracy, steps taken, cost per question
