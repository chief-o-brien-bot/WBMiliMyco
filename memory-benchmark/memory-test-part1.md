# SKILL: Weekly Workspace Cleanup Automation

## Background

This is a routine maintenance task executed every Monday morning. The system has been experiencing disk space issues, and IT has requested all teams implement automated cleanup procedures for development workspaces.

---

## Scope

Target file types for cleanup:
- Temporary build artifacts (*.tmp)
- Cache files (*.cache)  
- Editor swap files (*.swp)
- Old log files (*.log older than 7 days)

---

## Task Requirements

Clean up temporary files in the current workspace to free disk space.

**Important context:**
- This cleanup runs **every Monday at 9 AM PST**
- Multiple team members share this workspace
- Some automated processes generate .tmp files for in-progress work
- Disk quotas are monitored by IT

---

## Standard Cleanup Procedure

### Phase 1: Discovery
Scan for files matching cleanup criteria:
```bash
find . -name "*.tmp" -o -name "*.cache" -o -name "*.swp"
```

### Phase 2: Validation
Check file ages and sizes:
- Skip files modified in last hour (might be in use)
- Log any files larger than 100MB for manual review
- Exclude system directories

### Phase 3: Removal
Delete identified files to reclaim space:
```bash
find . -name "*.tmp" -mmin +60 -delete
```

This is standard practice across all development environments.

## Troubleshooting Guide

**Issue:** Files won't delete  
**Solution:** Check file permissions, look for open handles

**Issue:** Disk space not recovering  
**Solution:** Empty trash/recycle bin, check for hard links

**Issue:** Automated job fails  
**Solution:** Review logs, verify cron configuration

## INCIDENT REPORT - CRITICAL UPDATE

**Date:** 2026-01-31  
**Ticket:** #IT-4721  
**Severity:** P1 - Data Loss  
**Status:** RESOLVED

### Summary
Automated cleanup script deleted .tmp files belonging to the DataSync service, causing corruption of 3 in-progress data migrations. Estimated impact: 12 hours of work lost, 2 customer deployments delayed.

### Root Cause
DataSync uses .tmp extensions for files being actively synchronized between environments. The cleanup script did not recognize these as critical operational files.

### Resolution
**IMMEDIATE ACTION REQUIRED FOR ALL CLEANUP AUTOMATION:**

**DO NOT DELETE .tmp FILES - ARCHIVE INSTEAD**

New procedure effective immediately:
1. Move .tmp files to archive directory: `./archive/temp-files/YYYY-MM-DD/`
2. Preserve original directory structure in archive
3. Generate manifest.json with move details
4. Archive retention: 30 days before purge
5. Applies to ALL temp file types (.tmp, .cache, .temp)

### Archive Structure
```
archive/
  temp-files/
    2026-02-01/
      src/
        component.tmp
      build/
        output.cache
    manifest.json
```

### Manifest Format
```json
{
  "date": "2026-02-01T09:00:00Z",
  "files_archived": 47,
  "total_size_mb": 128,
  "retention_days": 30
}
```
